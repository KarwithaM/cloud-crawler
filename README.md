All AZ-900 concepts are based on the public Microsoft Learn skills outline. No real exam questions or Microsoft logos are used.*

## The Quest
Azure AZ-900 prep is usually a chore of dry PDFs and boring flashcards. **Cloud Crawler** transforms exam prep into an interactive, gamified RPG. Guided by an animated Wizard Tutor, learners "crawl" through three realms of cloud concepts, battling questions to grow their soul orb and unlock ancient lore.

## 🛠 Tech Stack & Architecture
Built rapidly using AI-assisted "Vibe Coding" tools:
- **Frontend & UI:** React, Tailwind CSS, Framer Motion (for the modular SVG Wizard animations).
- **Backend & Database:** Supabase (PostgreSQL) with Row Level Security (RLS) enabled for safe, live data fetching.
- **AI Prompting:** Structured, state-driven prompts used to generate complex game logic and UI components via Lovable.dev.

## 🎮 Core Features
1. **The Wizard Tutor:** A state-driven SVG character that reacts to your gameplay (waves, reads scrolls, pulls levers, shakes her head).
2. **Honest Quizzing Mechanics:** Gain +1 point for a first-try correct answer. Lose -0.5 points for a wrong guess. This prevents brute-forcing and rewards actual knowledge.
3. **Hybrid Lifeline:** A 9-block progress map tracks your quest completion, while a glowing "Soul Orb" tracks your fractional score and shifts colors as you level up.
4. **Three Realms:** Questions are batched into *Concepts*, *Architecture*, and *Governance*.
5. **Victory Scroll:** A post-game analytics screen showing your first-try accuracy, weak realms, and a direct link to the official Microsoft practice assessment.
